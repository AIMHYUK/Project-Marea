# 물 머티리얼 조정

> 상태: 진행중 · 갱신 2026-09-02 · 관련: [분담](1차_구현_분담.md), [설계 결정](설계_결정.md)
> 무엇: Uber Stylized Water 의 인스펙터에서 무엇을 만지면 무엇이 바뀌는지. 그리고 만져도 아무 일도 안 일어나는 값이 어떤 것인지.

셰이더가 노출하는 프로퍼티가 **103개**다. 대부분은 안 만진다. 여기 적은 게 실제로 쓰는 것들이다.

## 만지는 머티리얼은 둘

| | 무엇 |
|---|---|
| `Assets/Materials/UWa-Marea-Sea.mat` | 수면. `UWa-Template-Tropical` 복사본 |
| `Assets/Materials/Seabed-Sand.mat` | 바다 바닥. URP/Lit |

**`Assets/Shaders/Uber Stylized Water/Template Materials/` 안의 원본 8개는 만지지 않는다.**
서드파티라 에셋을 업데이트하면 통째로 덮인다.

---

## ⚠️ 먼저 — 토글부터 확인한다

기능 대부분이 **셰이더 키워드 토글** 뒤에 있다. 꺼져 있으면 셰이더가 그 분기를
**컴파일에서 아예 뺀다.** 그래서 값만 바꾸고 토글을 안 켜면 **아무 일도 안 일어난다.**
에러도 경고도 없다.

`UWa-Marea-Sea` 의 현재 상태:

| 토글 | 상태 | 켜면 |
|---|---|---|
| `_ENABLENORMAL` | **켜짐** | 노멀맵으로 표면이 일렁인다. Tropical 은 이게 표면 표현의 전부다 |
| `_Enable_Intersection` | **켜짐** | 물이 물체와 만나는 선에 거품 |
| `_ENABLECAUSTICS` | **켜짐** | 바닥에 빛 무늬 |
| `_ENABLEREFRACTION` | **켜짐** | 물 너머가 굴절 |
| `_ENABLESHORELINE` | **켜짐** | 밀려왔다 빠지는 물결선 |
| `_ENABLEWAVE` | 스크립트가 켬 | **정점이 실제로 출렁인다** |
| `_Enable_SurfaceFoam` | 꺼짐 | 수면 위에 떠다니는 거품 무늬 |
| `_ENABLE_UNDERWATERLAYER` | 꺼짐 | 카메라가 물속에 들어갔을 때 |

> **템플릿 8개 중 `Wavy` · `Wavy 2` 둘만 `_ENABLEWAVE` 가 원래 켜져 있다.**
> Tropical·Anime·Genshin·Murky·OldSchool·Clear 는 정점 파도를 안 쓰고 노멀맵으로만 표현한다.
> 이걸 모르고 파도 높이만 올리면 몇 시간을 날린다. 실제로 한 번 날렸다.

## 자주 만지는 값

### 색과 깊이

| 프로퍼티 | 지금 | 무엇 |
|---|---|---|
| `_Color_Shallow` | 하늘색 | 얕은 곳 색. **알파가 투명도**다 |
| `_Color_Deep` | 남색 | 깊은 곳 색 |
| `_Water_Depth` | `0.6` | **얕은색 → 깊은색이 완전히 벌어지는 수심.** 이 씬은 최대 수심이 0.6 |
| `_WorldSpaceDepth` | 켜짐 | 켜져 있어서 `_Water_Depth` 가 **월드 유닛**이다. 끄면 상대값이 된다 |

물이 통짜 파란 판으로 보이면 **십중팔구 밑에 아무것도 없는 것**이지 색 문제가 아니다.
이 셰이더는 "내 밑에 있는 물체까지 거리"로 색을 만든다. 밑이 비면 전부 최심부 색이 된다.

| `_InterSec_Color` | 거품 색 |

| `_InterSec_Foam_Pan` | 거품이 흐르는 방향·속도 |

메시가 실제로 출렁인다. **파도가 둘뿐이라 값을 잘못 주면 바로 격자가 보인다.**

|---|---|---|

| `_1st_Wave_Length` | `2.7` | 파장 |
| `_1st_Wave_Speed` | `1.0` | |
| `_1st_Wave_Direction` | `(1, 0, 0.15)` | 진행 방향 |
| `_1st_Wave_Sharpness` | `0.5` | 올리면 마루가 뾰족해진다 |
| `_2nd_Wave_Height` | `0.035` | 잔물결 |
| `_2nd_Wave_Length` | `7.3` | |
| `_2nd_Wave_Speed` | `0.62` | |
| `_2nd_Wave_Direction` | `(0.8, 0, -0.35)` | |
| `_2nd_Wave_Sharpness` | `0.15` | 둥글게 |
| `_Wave_Top_Color` | | 마루에 얹는 색 |

#### 파도가 균일해 보일 때 — 세 가지를 지킨다 `(+9/2)`

**1. 파장 비가 떨어지면 안 된다.**
`3` 과 `5` 는 최소공배수가 **15** 라 15유닛마다 똑같은 무늬가 반복된다.
물이 70x80 이니 화면 안에 **4~5번** 들어와서 바로 눈에 띈다.
`2.7` 과 `7.3` 처럼 비가 안 떨어지면 반복 주기가 화면 밖으로 나간다.

**2. 두 파의 방향이 직교하면 다이아몬드 격자가 생긴다.**
기본값 `(1,0,0)` 과 `(-1,0,1)` 은 **135도**라 체커보드가 된다.
실제 바다는 한 방향 스웰에 약간의 산포다. **사이각 30도쯤**으로 좁히면
격자 대신 긴 마루가 생긴다.

**3. 높이가 비슷하면 둘이 대등하게 싸운다.**
`0.07` / `0.05` 는 거의 같다. **주 스웰 / 잔물결**로 비를 벌린다.
속도와 샤프니스도 같이 다르게 준다 — 성격이 달라야 두 파로 안 읽힌다.

> **구조적 한계** — 이 셰이더는 정점 파도가 **2개뿐**이다. 진짜 바다는 4~8 옥타브를 겹친다.
> 2개로는 격자를 완전히 못 없앤다. **나머지는 노멀맵이 깨야 한다** (`_Normal_Strength`).
> 위 세 가지는 격자를 화면 밖으로 밀어내는 것이지 없애는 게 아니다.

## 만지면 안 되는 값 — 죽은 키

머티리얼 파일(`.mat`)을 텍스트로 열면 보이는데 **셰이더가 노출하지 않는** 항목들이다.
셰이더그래프에서 프로퍼티 이름이 바뀌었는데 Unity 가 `m_Floats` 의 고아 항목을 안 지워서 남았다.

**인스펙터에는 안 보인다.** 값을 바꿔도 아무 일도 안 일어난다.

```
_Depth_Distance          ← 진짜는 _Water_Depth
_WaterDepth              ← 진짜는 _Water_Depth
_CausticsDepth           ← 진짜는 _Caustics_Depth
_UnderWaterDepth         ← 진짜는 _UnderWater_Depth
_ShallowColor            ← 진짜는 _Color_Shallow
_Deep_Color              ← 진짜는 _Color_Deep
_ShoreLineDepth / _shoreLineDepth / _SL_Depth
_IntersectionFoamDepth / _IntersectionDistanceDepth / _Intersection_Foam_depth
_ParalaxDepth / _SurfaceFomShaodwDepth
```

**판별법** — `Shader/UberStylizedWater.shader` 의 `Properties { }` 블록에 있으면 살아 있는 것이다.
없으면 죽은 키다. 인스펙터에 보이는 것만 만지면 이 문제를 만날 일이 없다.

## 인스펙터 vs 스크립트 상수

`Marea > 물 세팅 만들기` 를 다시 누르면 **아래 값들을 스크립트 상수로 덮어쓴다.**

```
_ENABLEWAVE   _Water_Depth
_1st_Wave_Height  _1st_Wave_Length  _1st_Wave_Speed  _1st_Wave_Sharpness  _1st_Wave_Direction
_2nd_Wave_Height  _2nd_Wave_Length  _2nd_Wave_Speed  _2nd_Wave_Sharpness  _2nd_Wave_Direction
```

이 12개는 **인스펙터에서 조정하지 말고 `Assets/Editor/WaterSceneSetup.cs` 맨 위 상수를 고쳐라.**
나머지 91개는 스크립트가 안 건드리니 인스펙터에서 자유롭게 만져도 된다
(`_Normal_Strength` · `_Normal_Scale` · 색 · 물가 거품 · 코스틱 전부).

**인스펙터에서 파도까지 직접 맞추고 싶으면** 스크립트의 `TuneMaterial` 을 `false` 로 내려라. `(+9/2)`
그러면 메뉴를 눌러도 씬 오브젝트만 다시 만들고 머티리얼은 안 건드린다.

씬 배치(해변 기울기·수면 높이·크기)도 같은 파일 상수다.

```csharp
const float SeabedRotZ = -1.2f;   // 해변 기울기
const float WaterY     = 0.6f;    // 수면 높이
const float WaterDepth = 0.6f;    // 색이 벌어지는 수심
```

## 미확인

- **`_ENABLEPLANERREFLECTION` 이 켜져 있는데 프리팹에 관련 스크립트가 없다.**
  에셋에 `Planner Reflection/PlanarReflectionManager.cs` · `PlanarReflectionVolume.cs` 가
  따로 있는데 씬에 안 올라가 있다. 반사가 무엇으로 폴백하는지 확인 못 했다.
  이상해 보이면 이 토글을 꺼보는 게 첫 시도다.
- **모바일로 바꾸면 물이 납작해진다.** `Mobile_RPAsset` 은
  `RequireDepthTexture` · `RequireOpaqueTexture` 가 **둘 다 0** 이다.
  이 셰이더는 깊이 없이 성립하지 않는다(`LinearEyeDepth` 12회 사용).
  지금은 Standalone → `PC_RPAsset`(둘 다 1) 이라 문제없다.
- `Water Template Clear.prefab` 은 **에셋 자체 버그**다. 나머지 7개는 자기 템플릿
  머티리얼을 물고 있는데 이것만 개발용 `Shader/Devlopment/UberStylizedWater.mat` 을 참조한다.
